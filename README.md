# Learning Spatial Transmission Maps from Sparse Outbreak Snapshots with Diffusion Models

Code accompanying:

> A. W. Baggaley, *Learning Spatial Transmission Maps from Sparse Outbreak
> Snapshots with Diffusion Models*, Journal of the Royal Society Interface (2026).

The code implements a conditional EDM that infers a
spatially heterogeneous transmission field $\beta(x)$ from a small number of
sparse, and optionally thinned, infection snapshots generated by a stochastic
spatial SIR model on a lattice.

---
## 1. Requirements

The only substantive dependencies are PyTorch and Matplotlib

**Hardware.** Training was performed on a single NVIDIA GPU. All scripts select
the device automatically (CUDA, then Apple MPS, then CPU). Evaluation runs
comfortably on CPU but is slow; training on CPU is not recommended.


**LaTeX.** Several plotting scripts set `text.usetex=True` and therefore require a
working TeX installation. If you do not have one, set `use_tex = False` (or
`USE_TEX = False`) in the relevant script.

---
## 2. Configuration

The scripts are **not** driven by command-line arguments.
Each has a clearly marked block of constants near the top of `main()` (or
`train()`), labelled `USER SETTINGS`. Edit these, then run the script with no
arguments, e.g.

```bash
python <script>.py
```

## 4. End-to-end workflow

### Step 1 — Generate the training data

```bash
python SIRensemble.py
```

Writes `I_ensemble_M100_T5_10_15_20.pt` (shape `[M,4,H,W]`) and
`beta_ensemble_M100.pt` (shape `[M,H,W]`).

Each of the `M = 10000` ensemble members is a **distinct** transmission field
drawn from the generator, paired with a single stochastic SIR realisation on that
field. Infection indicators are recorded at $t_k \in \{5,10,15,20\}$.

Default settings correspond to the paper: `H = W = 128`, `gamma = 0.5`,
`beta0 = 0.2`, `beta_strength = 0.5` ($\xi$), `infected_fraction = 0.01`,
`base_seed = 42`, and eight iterations of the $5\times5$ smoothing filter.

> The filenames contain `M100` for historical reasons; they hold `M = 10000`
> members.


### Step 2 — Generate the held-out test data

Re-run the same script with a **different** `base_seed` and different output
paths, so that neither the transmission fields nor the outbreak realisations
appear in training. Edit the `__main__` block:

```python
M = 50                       # or larger
base_seed = 4242             # must differ from the training seed
save_path_I    = "I_ensemble_M100_T5_10_15_20_testing.pt"
save_path_beta = "beta_ensemble_M100_testing.pt"
```

then

```bash
python SIRensemble.py
```

To reiterate, for the out-of-training-regime experiment of Section 4(b), use the variant
script, which applies sixteen smoothing iterations instead of eight
($\ell \approx 10$ rather than $\ell \approx 7$):

### Step 3 — Train the models

Section 4 model, conditioned on unthinned snapshots:

```bash
python SIRdiffusionEDM_lognormal.py     # -> edm_beta_ckpt/ckpt_epoch_*.pt
```

Section 5 model, conditioned on thinned snapshots plus detection probabilities:

```bash
python edm_train_missingA_lognormal.py  # -> edm_beta_missingA_ckpt/ckpt_epoch_*.pt
```

### Step 4 — Reconstruction results (Section 4)

```bash
python edm_testset_eval_beta_firstM_pit_pub.py
```

Set `CKPT_PATH`, `TEST_M = 50`, `N_SAMPLES = 100`, and the test data paths.
Prints the metrics of Table 1 (column 1) and writes Figures 2 and 3.

For the out-of-training-regime column, point `I_TEST_PATH` and `BETA_TEST_PATH`
at the `*_ell10.pt` files, leaving `CKPT_PATH` unchanged — the model is **not**
retrained.

### Step 5 — Observation error (Section 5)

```bash
python edm_test_missingA.py
```

### Step 6 — Predictive performance (Section 5b)

```bash
python SIR_paired_forecast_distribution.py
```

Repeats the forecasting comparison across `N_REALISATIONS = 50` independent
outbreaks, each on a distinct held-out transmission field with the inference
performed afresh from that outbreak's thinned snapshots. Reports the distribution
of the paired log-score difference $\Delta_k$ (mean, spread, bootstrap
confidence interval, win fraction, exact sign test), together with a no-skill
reference forecast, at both forecast horizons. Writes
`paired_forecast_results.pt` for further analysis, plus the histogram, paired
scatter and risk-map figures.

---
## 5. Notes and caveats

**Stochasticity.** Data generation and sampling are seeded, so a given
configuration reproduces exactly on the same hardware. 

**Checkpoints are not included** in this repository owing to their size. Training
from scratch reproduces them, or contact the author.
